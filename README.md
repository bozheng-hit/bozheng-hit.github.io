# Bo Zheng

Personal research homepage: https://bozheng-hit.github.io/

Researcher at Qwen Team, Alibaba Group, working on model architecture and optimization for large language models.

## Edit

- `index.html`: biography, publications, experience, education, honors, and contact links. Long author lists use native HTML disclosures.
- `styles.css`: responsive layout and typography.
- `PublicSans-*.woff2`: locally served Public Sans fonts (regular, semibold, bold).
- `PublicSans-OFL.txt` and `PublicSans-LICENSE.md`: original font licenses. Font source: https://github.com/uswds/public-sans.
- `robots.txt` and `sitemap.xml`: search engine discovery.
- `.nojekyll`: publish the files directly.

All files live in the repository root. No JavaScript, installation, or build step is required.

## Publish

In **Settings → Pages**, select **Deploy from a branch**, **main**, and **/(root)**. Updates committed to `main` publish automatically.

If you later configure a custom domain in Pages settings, also update the canonical and Open Graph URLs in `index.html`, the sitemap URL in `robots.txt`, and the homepage URL in `sitemap.xml`.
