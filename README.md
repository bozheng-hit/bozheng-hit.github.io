# Bo Zheng

Personal research homepage: https://bozheng-hit.github.io/

Researcher at Qwen Team, Alibaba Group, working on model architecture and optimization for large language models.

## Edit

- `index.html`: biography, publications, experience, education, honors, and contact links.
- `styles.css`: responsive layout and typography.
- `robots.txt` and `sitemap.xml`: search engine discovery.
- `.nojekyll`: publish the HTML and CSS directly.

No installation or build step is required.

## Publish

In **Settings → Pages**, select **Deploy from a branch**, **main**, and **/(root)**. Updates committed to `main` will publish automatically.

If you later configure a custom domain in Pages settings, also update the canonical and Open Graph URLs in `index.html`, the sitemap URL in `robots.txt`, and the homepage URL in `sitemap.xml`.
